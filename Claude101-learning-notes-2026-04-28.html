板块一 · 我更认识 Claude 了

Claude 的本质：一个 Agent，三种交互形态

课程一开始就说 Claude 不是普通 chatbot，而是 thinking partner。学习的过程中我也越来越认识到——Claude 的整个设计逻辑就是 Agent（包括 Chat 在内）：能推理、能规划、能调用工具、能循环执行。Chat、Cowork、Code 的区别不是"Chatbot or Agent"，而是权限边界的递增。

注：Cowork 和 Code 底层是同一套引擎（Claude Code 架构）——Cowork 是面向知识工作者的 GUI 封装，Code 是开发者的 CLI/IDE 环境。

Memory：Agent 的"设计文档"

刚开始用 Claude 的时候没敢开 Memory，担心 AI 记太多会"变笨"。今天才知道，Claude 的 Memory 不是 read context，而是不断提炼用户画像：你是谁、你的偏好、你的工作方式。

重新理解 Memory

这就很 Agent——背后有一份随时可编辑的"设置文档"，它在学习你是谁，你也可以随时去 Settings 查看、修改、删除任何一条记忆。再加上个人偏好设置（Preferences）和 Styles，这套系统整体就是在让 Claude 越来越适配你这个用户。

板块二 · 方法论速览

用好 Claude 的底层逻辑

Prompt 三要素

和 Claude 说话，就像和一个聪明但不了解你背景的同事说话——信息越完整，结果越准。

①
Setting the Stage

你是谁？目标是什么？背景如何？给 Claude 足够的上下文。

②
Defining the Task

你想让 Claude 做什么？写、分析、搭建、研究——动作要明确。

③
Specifying Rules

格式、语气、长度、限制条件。给例子比说规则更有效。

4D Framework for AI Fluency

把"会用 AI"这件事拆成四个可操作的维度。

D
Delegation · 分配

哪些任务交给 AI，哪些留给人——战略判断，不是所有事都该 AI 做。

D
Description · 描述

有效传达意图——就是写好 prompt 的能力，让 AI 真正理解你要什么。

D
Discernment · 辨别

批判性评估输出——不照单全收，判断质量、准确性，知道哪里需要人工审查。

D
Diligence · 负责

对 AI 协助完成的工作承担责任——不能因为"AI 写的"就免责。

Evaluation：先测试，再信任

在把 Claude 深度嵌入某个工作流之前，做一次评估——这是方法论落地的关键一步，也是真正开始用 AI 的起点。

简单 Eval 四步

① 收集样本——找 5–10 个你日常做的同类任务的真实案例（你写的报告、你的分析）
② 写测试 prompt——用你实际工作时有的上下文，让 Claude 做同样的事
③ 对比输出——关键信息有没有？逻辑对不对？语气合不合？哪里它做得比你好？
④ 迭代 prompt——根据缺口补充上下文或示例，确定哪些步骤需要人工把关

板块三 · 让 Claude 触达更多

Connectors + Research 模式

Connectors：MCP = AI 的 USB-C

Connector 把 Claude 变成"有信息的协作者"——不必手动复制粘贴，Claude 直接读你的工具、在里面采取行动。背后的技术标准叫 MCP（Model Context Protocol），一个通用接口，任何工具都能接入。

类型
Web Connectors（远程）
Desktop Extensions（本地）
连接
Gmail · Google Drive · Slack · Notion · Asana · Linear · Stripe…
本地文件系统 · 剪贴板 · 本地应用（如 Figma）
同步
跨设备同步 ✓，Chat / Cowork / Code 均可用
不跨设备 ✗，仅 Claude Desktop / Code
适合
日常 SaaS 工具，随时随地访问
私人本地数据，权限更深、延迟更低

Chrome 扩展是补位工具——给 Claude 补了"浏览器里的手"，能操作任何没有 API 的网站，填补 Connector 覆盖不到的空白。

Research 模式：场景不同，开的模式不同

速查
Web Search

单次联网，查事实、查近况。快，浅。

深度研究 ★
Deep Research

多轮搜索，自主规划路径，输出结构化报告。真正的 Agent 行为。

深度推理
Extended Thinking

延长内部推理链，用于复杂判断。不联网，靠模型自身深度。

企业专属
Enterprise Search

接入内部知识库，搜私有数据源。Team / Enterprise 可用。

个人思考 · AI 时代对人的要求变了

当 AI 可以做这些事，人的价值在哪里？

看到 Research 功能，作为 Finance&Accounting背景的人，第一反应是回想起读书时打商赛和金融实习的经历，desktop research、financial modeling、data analysis、due diligence support……这些最被看重的技能，现在都可以交给 AI 了。

Finance 可以用 Claude 做 financial models、draft investment memos；Marketing 做 campaign analysis；Legal 做 discovery review……每一个曾经需要人来执行的分析类工作，现在都有了对应的 AI 路径。很多人已经给自己搭了一套 Agents——每个 Agent 负责一个角色，一个人就是一支队伍。

很多人上班，有人告诉他们该做什么——执行有价值。而进入 AI 时代，执行层被 AI 接管。对“人”而言，相比"做事的能力"，知道要做什么可能越来越重要了。能提出需求，懂底层逻辑，会验证结果，和 AI 打好配合——是我们在 AI 时代需要去不断增进的。
